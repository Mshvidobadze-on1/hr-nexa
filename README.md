# HR NEXA — SaaS HR, Talent Management & Employee Wellbeing Platform

საქართველოს ბაზარზე მორგებული სრული საწარმოო დონის HRMS, ტაბელის, ხელფასების, სასწავლო (LMS), შიდა სოციალური ქსელისა და FinTech (EWA) პლატფორმა.

---

## 🚀 სწრაფი გაშვების ინსტრუქცია

პროექტის გასაშვებად საჭიროა **Node.js 18+**:

```bash
# 1. დამოკიდებულებების ინსტალაცია
npm install

# 2. დეველოპმენტ რეჟიმში გაშვება
npm run dev

# ან პროდაქშენ ბილდი და გაშვება:
npm run build
npm start
```

ამის შემდეგ გახსენით ბრაუზერში: [http://localhost:3000](http://localhost:3000)
